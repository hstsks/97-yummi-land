# Resource Pack Custom Asset Overrides (`yuumi97`)

Any `.json` model or `.png` texture placed inside this `overrides/` directory (mirroring Minecraft `1.21.4` `assets/yuumi97/...` structure) automatically overrides or extends the baseline procedural sprites in `PackBuilder.java` whenever `scripts/build-all.ps1` is executed.

See `e:\MinGem\CODEX_ASSET_BRIEF.md` for full 3D modeling and pixel-art specifications.
