# 🐱 유미의 97랜드 v2.0 (Yuumi's 97Land) — 호스트 운영 & 컨텐츠 매뉴얼

리그 오브 레전드의 마법 고양이 **유미**와 **문턱의 서** 세계관을 모티브로 구축된 **8인 무인 자율 운영 RPG × 생활/부동산 × 카지노 방송형 서버(v2.0)** 입니다.

## GitHub에서 복제한 개발 환경 준비

저장소에는 플러그인 소스, 리소스팩 모델·텍스처, 에셋 제작 원본과 실행·빌드 스크립트를 보관합니다. `server/`, `runtime/`, 운영 백업, 테스트 서버 데이터, 빌드 캐시는 `.gitignore`로 제외합니다. 월드·플레이어 정보, 경제·분양·도감 진행도와 개인 금고는 로컬에만 남으며 GitHub로 백업되지 않습니다.

처음 복제한 폴더에서 PowerShell로 다음 명령을 순서대로 실행합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\bootstrap-runtime.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\download-ecosystem.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\build-all.ps1
```

이 과정은 포터블 Java 21·Gradle·Paper와 외부 플러그인을 준비하고 자체 플러그인·리소스팩을 빌드합니다. 기존 서버의 운영 설정과 월드·플레이어 데이터는 복원하지 않습니다. 서버를 실행하기 전에 EULA 동의와 운영 설정을 별도로 준비하고, 기존 운영 환경을 옮길 때는 별도 백업에서 복원하세요. 아래의 폴더 전체 복사 안내는 런타임과 운영 데이터가 이미 준비된 로컬 서버에 해당합니다.

## 1. 서버 실행 방법 (32GB 동시 플레이 PC 최적화 완료)
1. 루트 폴더의 **`START_SERVER.bat`** 파일을 더블클릭합니다.
   - 포터블 `Java 21`이 내장되어 있어 별도의 자바 설치가 필요 없습니다.
   - 기본 `8GB RAM` (`-Xms8G -Xmx8G` + Aikar's G1GC 플래그)으로 구동되어, 호스트가 같은 PC에서 마인크래프트를 켜고 플레이해도 렉 없이 쾌적합니다.
   - 추후 다른 전용 PC로 옮길 때는 **`e:\MinGem` 폴더 통째로 복사**만 하면 그대로 실행됩니다.
2. 호스트 본인이 같은 PC에서 접속할 때는 멀티플레이 서버 주소에 **`localhost`** 를 입력하면 됩니다.
3. 서버를 안전하게 종료할 때는 콘솔 창에 **`stop`** 을 입력하세요 (종료 시 `backups/` 폴더에 자동으로 롤링 백업 압축본이 생성됩니다).

## 2. 외부 지인 접속을 위한 공유기 포트포워딩 (최초 1회)
공유기 관리자 페이지(예: ipTIME `192.168.0.1`)의 **포트포워딩** 메뉴에서 호스트 PC의 내부 IP로 아래 포트를 열어주세요.

| 프로토콜 | 외부/내부 포트 | 용도 | 필수 여부 |
| :--- | :--- | :--- | :--- |
| **`TCP`** | **`25565`** | 마인크래프트 기본 게임 접속 | **필수** |
| **`UDP`** | **`24454`** | `Simple Voice Chat` 인게임 근거리 음성채팅 | **필수 (반드시 UDP!)** |
| **`TCP`** | **`25566`** | `Yuumi97Pack.zip` 커스텀 리소스팩 자동 전송 서버 | **필수** |
| **`TCP`** | **`8100`** | `BlueMap` 웹 브라우저 실시간 3D 서버 지도 (`http://공인IP:8100`) | 선택 |

## 3. 정식 오픈 전 권장: 야생 월드 사전 청크 생성 (`Chunky`)
야생 원정 월드(`world`)에는 대형 지형·던전 데이터팩(`Terralith`, `Structory`, `Dungeons and Taverns`, `Incendium`, `Nullscape`)이 탑재되어 있습니다. 오픈 전 콘솔에 아래 3줄을 입력해 사전 생성을 돌려두시면 탐험 렉이 완전히 사라집니다:

```text
chunky world world
chunky radius 3000
chunky start
```
