# v3.1 랜드마크 시각 검수 기록

2026-11-15. 승인된 범위: 신규 복셀 랜드마크 6종, 기존 29종/57아이콘 보존. 확장 지시서의 NBT 9종은 이번 납품 범위가 아니다.

## 실제 관찰 환경

- Blender 5.2.1 LTS, Cycles 20 samples, RTX 3070 / OPTIX. Standard, exposure −0.7, nearest texture.
- 납품 JSON과 PNG를 읽어 이름 붙은 cuboid 메시와 UV로 구성한 뒤 `.blend`에 텍스처를 패킹해 저장했다. 모델마다 새 Blender 프로세스로 다시 열어 원본 JSON/PNG·장착 메타데이터 SHA256과 패킹 상태를 확인하고 렌더했다.
- 기본 4뷰: 정면, 측면, 후면, 3/4, 각 640×640. 최종 6행×3열 시트는 정면·측면·3/4 18장으로 구성했다. 후면은 개별 폴더와 4뷰 시트에 보존했다.
- 장착 지그는 wall 2, ceiling 1, floor 2, gate 1이다. 왕좌는 전방 고양이 크기의 단순 cuboid 참고물을 추가했다. 이는 실제 바닐라 고양이 메시·히트박스가 아니다.
- 원거리: 마키 scale 2.7, 시계 scale 2.0, 16m/32m, 70° FOV, 640×640 정면 원근. 두 거리에서 조명은 동일하다. 기준 스케일 적용 시 조명 에너지에 scale², area size에 scale을 적용해 불필요한 밝기 저하를 보정했다.
- 제작자 및 주 검수자가 실제 저장된 PNG를 열어 관찰했다. 이미지의 존재나 생성 로그만으로 시각 통과를 판정하지 않았다.

## 관찰에 따른 수정

1. 마키의 초기 정면/3/4에서 금색 판이 벨벳을 가렸다. 원인은 안쪽 판의 전면 Z가 바깥 금색 판보다 뒤에 있는 깊이 순서였다. shadow → velvet → tuft를 −Z 방향으로 꺼내고 필라스터·하단 inset 깊이를 맞췄다. 같은 기본 카메라·조명으로 다시 렌더해 진홍색 노출과 노란 7의 대비 개선을 확인했다. 수정 전 원본·JSON·PNG·blend·다각도/거리 렌더는 `backups/v31-before-marquee-depth-fix`에 있다.
2. 더미의 스프링 양끝 작은 틈은 소켓 상단 2.7→3.1, 압축판 하단 9.25→9.0으로 보완해 0.1 단위씩 연결했다. 낮은 벚꽃 두 송이에는 꽃자루를 추가했다. 동일 기본 카메라/조명에서 재렌더해 접합과 기존 실루엣 보존을 확인했다. 수정 전은 `backups/v31-before-join-fix`에 있다.
3. 초기 큰 스케일의 장착 지그는 조명만 멀어져 기본 뷰보다 어두웠다. 모델 색을 바꾸지 않고 조명 에너지·면광원 크기를 기준 스케일에 맞춰 보정했다. 최초 장착 이미지는 `backups/v31-before-light-fix`에 보존했다. 이 이전 장착 이미지를 모델 품질의 전후 비교로 사용하지 않는다. 형상 수정의 비교는 조명이 동일한 기본 4뷰에서 했다.

## 산출물과 검증 경계

- `landmarks-v31.png`: 필수 18칸 시트. `landmarks-v31-contexts.png`: 장착/딜러 참고 7장. `landmarks-v31-distance.png`: 원거리 4장. 개별 기본 뷰는 24장, 편집 가능한 `.blend`는 6개다.
- 실제 납품과 검사 수치·최종 SHA256는 `v31-delivery.json`, 정적 검사는 `static-validation-v31.json`에 기록한다. 모델/아틀라스 35종, 아이콘 57종, GUI 18종, item definition 29종, override 175파일이며 이전 atlas 제외 156파일과 기존 검수 증거 200파일의 보존을 검사한다.
- 남은 확정 조형 결함은 관찰하지 못했다. 실제 Minecraft 리소스 로딩, SOL의 배치 좌표/yaw, 서버 엔티티 변환과 히트박스, 야간 조명은 미실행이다. 밝은 도색은 자체 발광 검증을 의미하지 않는다. 현장 장착 수식과 기준점은 `README_V31.md`에 기록했다.
- `-Build`, PackBuilder, Gradle, 서버 실행·배포는 하지 않았다. Java 플러그인·scripts·server 파일을 변경하지 않았다.
