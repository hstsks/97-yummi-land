# Stream 02 최종 검수 기록

검수일: 2026-11-16 (Asia/Seoul). 건축 납품 범위 완료. 적용한 작업 깊이는 High: 기능 좌표·충돌·연결의 독립 검사와 실제 출력물의 다각도 시각 검수를 함께 수행했다. 시간·비용을 품질의 근거로 삼지 않았으며 과금·토큰 사용량은 계측되지 않았다.

도구 시계로 확인한 구현 계측 구간은 KST 06:01:13–06:25:40, 24분 27초이다. 병렬 에이전트 시간을 중복 합산하지 않았다. 이전 계획 수립 대화는 이 구간에 포함하지 않는다.

## 실제로 확인한 결과

- 지정된 Gzip NBT 20종, 전체 704,299셀, DataVersion 4189, 빈 entities, 금지 블록 없음.
- 세 던전을 각각 6모듈로 조립했을 때 15개 인접 접속면의 9폭×8높이 AIR와 바닥 연결 통과.
- 실제 1.21.4 블록 상태·충돌 형상으로 허브 네 방향 출입, 집기 접근, 두 발코니 계단, 보물 분기, 쉼터, 퍼즐 기단, 보스·귀환 동선 통과.
- 대공방 유효 인챈트 책장 26개, NPC 패드·키오스크 홀로그램 AIR·시계판 외측 공간 확인.
- 사용자 확정 원형 장미창: 지름 19, local Y11..29. 네 엄폐 기둥의 불투명 코어와 높이 확인.
- 독립 prismarine-nbt 2.8.0 파서가 20종 전체 트리에서 자체 reader와 일치하고 prismarine-block의 상태 ID도 일치.
- 검증기 결함 주입 6개 시나리오 통과. 재빌드한 20개 NBT와 manifest 총 21파일의 SHA-256 일치.

수치 결과는 `verification-report.json`, `validator-tests.json`, `independent-parser-report.json`, `reproducibility-report.json`에 남겼다. 이미지가 참조한 파일 해시는 `render-evidence.json`에 기록했다.

## 시각 관찰과 수정

전체 허브 시트와 18모듈 시트, 대서고 복층 홀·협곡, 용광로 대교·보스 홀, 수정 성당 보스 홀 및 키오스크 확대 이미지를 직접 열어 확인했다. 독립 검수 에이전트도 출력 NBT와 렌더를 확인했다.

| 발견한 문제 | 채택한 수정과 확인 |
|---|---|
| 키오스크의 외곽 계단 시작점에서 플레이어 폭이 윗단에 닿을 수 있음 | 계단을 한 칸 안으로 옮겨 외곽 디딤 공간 확보. 4방향 경로와 180개 연결 표본 통과. |
| Zone4 북측 하행 계단 검수 좌표가 위쪽 반칸을 침범 | 실제 계단의 하부 발 위치를 z2.15로 수정. 세 테마의 전체 경로 재검증 통과. |
| 도가니·수정 왕관의 사슬 끝과 볼트 사이에 AIR 한 칸이 남음 | 실제 x 위치의 볼트 높이에 맞춰 연장. 원형 도가니 사슬은 그릇과 닿는 네 방위 테두리에 고정. |
| 대서고 천문대가 평면 반원 창으로만 표현됨 | 반경 10의 깊이 있는 상부 반구 외피, 받침과 지지 기둥, 별도 망원경을 추가. 최종 확대 렌더에서 입체 깊이와 망원경 확인. |
| 로비의 단일 물먹은 계단이 옆으로 물을 흘릴 가능성 | 광원 바닥과 석재 벽을 갖춘 소형 성수대로 교체. 유체 셀 측면·하부의 열린 출구가 없는지 별도 검사. |
| 초기 절개 범위가 하부 심연을 가리고 망원경·엄폐 기둥까지 잘라냄 | 가까운 기단 벽과 동측 지붕 외피만 선택 절개. 실제 블록 변경 없이 내부 조형·층고·하부 광원 노출. |
| 충돌용 정육면체로 표시한 구리 격자가 용암을 가림 | 렌더에서 격자를 얇은 격자 부재로 표시. 검증의 실제 충돌 AABB는 그대로 유지. |
| 시계판 배경 블록과 외측 부착 평면의 용어가 혼용됨 | 시트에는 외측 평면 X3/X10/Z3/Z10을 명시하고 manifest의 local `clockMounts`와 일치시킴. |

허브는 벚꽃·백금 회랑과 금장 시계탑의 높이 위계, 시설 사이의 여백을 확인했다. 대서고는 청록 유리 바닥·백색 열주·서가·혼천의, 용광로는 검은 석재·구리 격자·용암·거신 흉상, 수정 성당은 백색 리브·보라 파편·원형 장미창의 구분을 확인했다. 요구한 단면·평면·아이소메트릭 검수 자료에 필요한 기하와 색 관계가 보인다.

초기 허브 검수 이미지는 `iterations/`에 두었으며 최종 납품 이미지와 구분한다. 최종 시트는 동적 NPC·보스·성문이 없는 건축 자체를 보여 준다.

## 완료 범위와 남은 통합 확인

최종 NBT·manifest, 편집 가능한 생성 소스, 자동 검증기, 두 필수 시트 및 20개 확대 이미지가 완성되었다. 쓰기는 `assets/architecture-blueprints/**`와 `yuumi-core/src/main/resources/structures/overhaul/**` 안에서만 수행했다.

이 이미지는 실제 저장된 NBT를 읽은 컬러 도식이다. Minecraft 기본 텍스처·실제 조명 전파·게임 렌더와 동일한 화면이라고 주장하지 않는다. 정적 유체 경계와 플레이어 충돌을 검사했지만 유체 틱·전투·성문 애니메이션을 실행하지 않았다.

현재 코어의 신규 구조물 로딩·NPC·게임 기믹 부착·서버 스탬핑은 Stream 03 인계 사항이다. 이 작업에서는 Java·리소스팩·서버·공용 스크립트를 수정하거나 통합 Gradle 빌드를 실행하지 않았다. 그에 따른 인게임 통합 결과는 미검증으로 남긴다.
